安裝

本套件直接提供原始碼（不需 build），從 GitHub 安裝並指定版本 tag：

npm i "github:Mendesky/mendesky-ds-angular#<版本 tag>"

版本 tag 見下方「版本」或 版本說明。

使用端還要做三件事，細節與原因見 README：

  1. tsconfig.json 的 paths 把 @mendesky/ds-angular 指到專案根目錄的 symlink（由 postinstall 建立）。
  2. angular.json 的 build 與 test 都開 preserveSymlinks。
  3. 全域樣式 @use 'core';，並在 index.html 載入 Noto Sans TC 字型；用到 PDF 預覽時提供 assets/pdf.worker.min.js。

快速上手

元件都是 standalone，直接放進 imports：

import { Component } from '@angular/core';
import { ButtonComponent } from '@mendesky/ds-angular';

@Component({
  selector: 'app-demo',
  standalone: true,
  imports: [ButtonComponent],
  template: `<app-button variant="filled" color="primary" text="確認" (btnClick)="save()"></app-button>`,
})
export class DemoComponent {
  save() {}
}

每個元件該用在哪裡、不該用在哪裡，寫在元件文件每一頁最上方。寫原生 <button>、自刻下拉之前，先查有沒有現成元件。
